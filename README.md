# Python Calculator

A simple calculator application built using Python and Tkinter.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Error handling for invalid input
- Division by zero protection

## Technologies Used

- Python
- Tkinter

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Go to the Task-1-Calculator folder.
4. Run:

```bash
python calculator.py
